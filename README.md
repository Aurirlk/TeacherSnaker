# 程序设计基础教学辅助——贪吃蛇游戏

## 项目简介

本项目是一份面向高职/专科院校《程序设计基础》（C 语言方向）课程的期末大作业教学资源包。以"贪吃蛇游戏"为载体，采用**原始版 + 后期迭代**的交付模式，兼顾游戏趣味性与知识点覆盖，难度经过精心控制——恰好处于学生需要认真投入才能完成、但常见 AI 工具（如豆包）难以直接生成完整代码的水平。

## 教学理念

| 设计要点 | 说明 |
|---------|------|
| **渐进式交付** | 先做核心功能，再逐步添加菜单、存档、排行榜等模块，让学生体验"从能用到好用"的迭代过程 |
| **脚手架式学习** | 从简单的链表增删改查（学生管理系统）起步，再过渡到贪吃蛇核心逻辑，最后到完整产品 |
| **代码即教材** | 所有源码均包含详尽的简体中文注释，解释算法原理、数据结构选择和设计决策 |
| **防 AI 作弊** | 题目有足够的自定义逻辑（双缓冲渲染、MCI 音乐控制、Unicode 边框绘制等），通用 AI 难以一次生成可编译运行的完整答案 |

## 各文件夹详细说明

### 1. `vc6.0_cn_full（...）.exe等` —— 开发环境

内有经典的VC6.0和Dev-C++ 5.11 完整绿色版安装包，支持 Windows XP / Win7 / Win8 / Win10/ win11等等操作系统。各位同行不用担心环境问题。双击即可安装，适合机房批量部署。所有 `.dev` 项目文件和VC文件均可直接打开。

### 2. `学生管理系统/` —— 入门练习（C 语言链表）

- **`stu.cpp`**（359 行）：基于**单向链表**的完整学生信息管理系统
  - 功能：添加、删除、修改、查找、显示全部
  - 知识点：结构体、动态内存分配（`malloc`/`free`）、链表遍历、菜单式控制台交互
  - 包含完整中文注释
- **`main.cpp`**（注释备用版）：含教师结构体、文件读写、角色登录等扩展功能

> 教学定位：让学生先掌握链表的基本操作，为贪吃蛇的身体结构（双向链表）打下基础。

### 3. `学生管理系统 python/` —— 拓展参考

- **`student.py`**（303 行）：面向对象的 Python 版学习管理系统
  - 知识点：类与对象、JSON 持久化、学习统计
- 用于对比编程语言的教学设计、或为 Python 方向班级提供参考资料

### 4. `原始版代码（只保留原始功能）/` —— 教学起点

- **`main.c`**（395 行）：只包含贪吃蛇**核心游戏逻辑**
  - 用**双向链表**存储蛇的身体
  - 20×40 游戏地图，边框为墙壁
  - 食物随机生成、碰撞检测（墙壁/自身）、动态速度
  - WASD / 方向键控制、暂停（P）、退出（Q）、保存（F5）
  - 使用 `mmsystem.h` + `winmm.lib` 播放背景音乐
  - 文件中每行均有教学性中文注释

> **教学定位：学生在此基础上进行功能迭代**。原始版是"能玩"的起点，要求学生自行添加主菜单、难度选择、排行榜、存档系统等功能。

### 5. `最终版/` —— 交付目标（完整产品）

- **`main.c`**（1652 行）：在原始版基础上完整迭代后的最终产品，新增了以下模块：

| 模块 | 说明 |
|------|------|
| **主菜单系统** | Unicode 双线框绘制，6 项菜单：新游戏、读取存档、游戏规则、排行榜、游戏设置、退出 |
| **玩家命名系统** | 支持自定义昵称或自动分配 GuestX 编号，编号会自动扫描排行榜文件去重 |
| **三级难度选择** | 简单（200ms）、普通（150ms）、困难（100ms）逐帧间隔 |
| **存档/读档** | 二进制文件 `snake_save.dat` 存储：玩家名、分数、蛇长、方向、食物坐标、难度、蛇身完整位置 |
| **排行榜系统** | `fraction.txt` 文本文件持久化，排序后格式化展示 Top 10 |
| **音频系统** | MCI 接口播放 MP3/WAV 背景音乐，`Beep()` 实现吃食物/游戏结束音效，支持音量调节 |
| **色彩主题** | 5 套控制台配色方案可选 |
| **视觉增强** | 双线框装饰菜单、暂停覆盖遮罩、死亡动画（换色闪烁 + 音阶下降）、蛇身方块渲染、食物心形符号 |

### 6. `运行界面(作为展示）/` —— 课堂演示

- `贪吃蛇.exe`：可直接运行的完整游戏
- `SnakeMusic.mp3`：游戏背景音乐
- `fraction.txt`：示例排行榜数据
- `snake_save.dat`：示例存档数据
- `贪吃蛇游戏完整功能详细设计文档与教学指南.docx`：详细设计文档

> 课堂使用时，可直接运行演示最终效果，让学生对目标有直观认知。

## 建议教学流程

| 阶段 | 内容 | 课时 |
|------|------|------|
| **1. 铺垫** | 讲解链表结构，让学生完成"学生管理系统"的增删改查 | 2~4 课时 |
| **2. 讲解** | 发放原始版代码，讲解贪吃蛇核心逻辑（双向链表移动、碰撞检测、游戏循环） | 2 课时 |
| **3. 实践** | 要求学生基于原始版进行功能迭代，自行添加菜单、存档、排行榜等模块 | 课外 2~4 周 |
| **4. 验收** | 学生提交最终版代码 + 运行演示，教师展示最终版对比 | 1 课时 |

## 技术栈

- **语言**：C（C99 标准）
- **IDE**：Dev-C++ 5.11（附在仓库中）
- **图形**：Windows 控制台（无第三方图形库）
- **音频**：Windows MCI API + `kernel32.dll`（`Beep`）
- **编译依赖**：编译时需链接 `-lwinmm`

## 知识点覆盖

- 结构体与 `typedef`
- 双向链表（创建、遍历、插入头节点、删除尾节点、释放）
- 动态内存管理（`malloc` / `free`）
- 文件 I/O（文本文件排行榜 + 二进制文件存档）
- 控制台编程（光标定位、颜色设置、隐藏光标）
- 游戏循环模型（输入 → 更新 → 渲染）
- 碰撞检测算法（边界 / 墙壁 / 自身）
- 状态机设计（菜单态 / 游戏态 / 暂停态 / 死亡态）
- 模块化程序设计（核心逻辑与 UI 分离）

## 常见问题

**Q: 为什么用 Dev-C++ 而不是 VS Code？**
A: 高职机房环境多样，Dev-C++ 绿色免安装、体积小、对旧系统兼容性好，且 MISRA C 风格友好。

**Q: Python 版学生管理系统是做什么用的？**
A: 部分院校同时开设 Python 课程，此版本供教师灵活选用或作为课程之间的过渡参考。

**Q: 音乐播放不了怎么办？**
A: 检查是否在项目选项中链接了 `-lwinmm`，以及 `SnakeMusic.mp3` 是否与 exe 在同一目录。
